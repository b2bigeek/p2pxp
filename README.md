# P2PXP — Peer-to-Peer eXchange Protocol

Encrypted, direct peer-to-peer file transfer and chat. No cloud storage, no accounts to email — add a contact by user ID and send files and messages straight to their device.

## Download

Get the latest build for your platform from the [Releases](https://github.com/b2bigeek/p2pxp/releases) page.

- **macOS** — `.dmg` (signed and notarized, works on Apple Silicon and Intel)
- **Linux (arm64)** — `.deb`, `.rpm`, or `.AppImage`
- **Windows** — coming soon

## About

P2PXP uses end-to-end encryption (ChaCha20-Poly1305, Ed25519, X25519) for all messages and file transfers. A signaling server only introduces two devices to each other — it never sees your message or file contents.
